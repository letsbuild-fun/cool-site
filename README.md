# cool-site

A simple, playful single-page website: an animated gradient headline, an interactive particle field (follows your cursor, bursts on click), and light/dark themes.

No build step or dependencies — just `index.html`, `style.css`, and `script.js`.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

## Publish with GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: `main`, folder `/ (root)`.
